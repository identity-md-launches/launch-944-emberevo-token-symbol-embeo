## 查詢頁的解讀與限制

1. 本池尚未收集：用固定 launch 944 的模擬查詢，顯示專案份額估算。
2. 待補付：Factory 對此錢包／幣種的共用欠款，付款成功後才歸零。
3. 已付款：掃描指定期間的 FeesPaid，並核對成功交易收據。事件未帶 launchNumber，頁面維持錢包／Factory 範圍，不能一律宣稱是本池終身收入。
4. 任何模擬、事件掃描或收據驗證失敗，相關金額保持 `null`／「未確認」，不能補零。初次掃描遇 HTTP 403 的原始失敗保留；另一次讀取已補齊。
5. 最多掃描 80000 個區塊、每段 2000 個、最多 80 個事件交易；超出範圍顯示歷史資料不足，日後須另加可信分頁索引器。未知部分不因缺少完整索引而假定為零。
6. 公開 RPC 可能限制流量或 CORS。畫面保存原快照及時間；無法更新時不將其冒充即時資料。

Factory 原始碼顯示 `claimFees` 會嘗試付款；拒收時記入 `owed`，可由 `withdraw` 補付。這些交易入口只作語義說明，原型沒有執行按鈕。Token 本身依然是無 transfer tax 的 ERC-20，池交易費用與普通轉帳分開。
